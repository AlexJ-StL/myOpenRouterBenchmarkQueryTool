# Codex CLI

## Add server

```bash
codex mcp add openrouter --url https://mcp.openrouter.ai/mcp
codex mcp login openrouter
```

The second command opens the browser OAuth flow.

## Config reference

- Client: `codex`
- Command: `mcp add` with `--url`
- Auth: `mcp login openrouter`

Reference: docs (`OpenRouter Docs - MCP.md`), lines 31–34.
