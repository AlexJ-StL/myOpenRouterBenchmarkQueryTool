# docs/

This directory exists as a placeholder for longer-form documentation that does not
belong in `README.md`.

Currently the project is small enough that the README covers everything a user or
contributor needs. If the project grows, deeper guides belong here.

---

## Intended Structure

| File | Purpose |
| :-- | :-- |
| `ARCHITECTURE.md` | High-level design: data flow, module boundaries, and why the code is structured the way it is. |
| `API.md` | Detailed reference for the OpenRouter `/v1/benchmarks` response fields used by this tool. |
| `DESIGN_DECISIONS.md` | Rationale for non-obvious choices (cache eviction strategy, retry policy, CSV flattening, etc.). |

Nothing in `docs/` is required to run or contribute to the project today.
